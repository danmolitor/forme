Forme redacts by removing content from the file, not only hiding it behind a black box.

<Warning>Use Forme 0.33.0 or later for redaction. Output from earlier versions can still contain the redacted content. If you redacted documents with an earlier version, regenerate them from the originals.</Warning>

---

## Why Black Boxes Aren't Enough

A black rectangle drawn over text in a PDF does not remove the text — it only hides it visually. The text remains in the PDF content stream and can be extracted by:

- Copying and pasting from the PDF
- Using PDF text extraction tools
- Inspecting the raw PDF file

This is not a theoretical risk. Improperly redacted court documents, government filings, and legal briefs have leaked sensitive information because authors used annotation-based "redaction" tools that only add a visual overlay.

---

## How Forme Redacts

When you redact a PDF, Forme:

1. **Reads the whole document** — including compressed object streams and every earlier revision, so it works on the content a viewer shows.
2. **Finds what lies under each region** — text positions come from the font's glyph widths and the page's transforms, so text is located where it is drawn.
3. **Removes page content** — text and images under a region are removed from the page. The spacing is kept, so the rest of the line does not move. Lines, shapes, and clipping paths are cut at the region's edges, so their parts outside the region stay and nothing of their shape remains inside it.
4. **Removes hidden copies** — matching text is removed from annotations, links, bookmarks, and alternate text.
5. **Removes document data** — XMP metadata, embedded files, and document JavaScript are removed, and the document information is replaced (`/Producer` is "Forme").
6. **Draws a visual overlay** — a black (or custom-colored) rectangle marks each redacted area.
7. **Writes a new file** — the output holds only the content the document still uses. Earlier revisions and unused objects from the input are not carried over.

If Forme cannot redact some content safely, it returns an error instead of a PDF. See [Known Limitations](#known-limitations).

## Three Ways to Redact

### 1. Coordinate Regions

Region coordinates are in points on the page **as displayed**: `x` and `y` are measured from the top-left corner of the visible area (the CropBox), after the page's `/Rotate` is applied. These are the coordinates a PDF viewer shows, and the ones `findTextRegions` returns.

Draw precise rectangles over areas to redact. Best for known, fixed layouts where content position is predictable. This is what the dashboard's "Draw" mode uses.

```json
{
  "pdf": "<base64>",
  "redactions": [
    {"page": 0, "x": 100, "y": 200, "width": 150, "height": 20}
  ]
}
```

### 2. Text Search

Find text by literal string or regular expression. Best for dynamic content where you know what to redact but not exactly where it appears.

```json
{
  "pdf": "<base64>",
  "patterns": [
    {"pattern": "Jane Doe", "pattern_type": "Literal"},
    {"pattern": "\\d{3}-\\d{2}-\\d{4}", "pattern_type": "Regex"}
  ]
}
```

### 3. Presets and Templates

Use built-in presets for common sensitive data types, or save reusable sets of patterns as [redaction templates](/hosted-api/redaction-templates).

```json
{
  "pdf": "<base64>",
  "presets": ["ssn", "email", "phone"],
  "template": "hipaa-patient-record"
}
```

**Available presets:**

| Preset | Pattern |
|--------|---------|
| `ssn` | US Social Security Numbers (XXX-XX-XXXX) |
| `email` | Email addresses |
| `phone` | US phone numbers |
| `date-of-birth` | Date patterns (MM/DD/YYYY, YYYY-MM-DD, etc.) |
| `credit-card` | Credit card numbers |

All three methods can be combined in a single request.

## Verifying Redaction

Selecting text in a viewer only checks what the page shows. It does not check the rest of the file. Check the output with a tool other than the one that redacted it:

1. Extract all text with a separate tool (for example `pdftotext redacted.pdf -`) and search it for the redacted values.
2. Check the document properties, bookmarks, comments, and attachments.
3. Confirm that values you did not redact are still there, so you know the check works.

Do not rely on Forme's own text search (`findTextRegions`) to confirm a Forme redaction.

## Known Limitations

- **Whole text runs**: A text run is removed whole when any of its glyphs is under a region (at least a fifth of the glyph's box, in each direction). If the match shares a run with other words (for example a label on the same line), those words are removed too.
- **Images**: An image under a region is removed whole, even where most of it lies outside the region. Text inside an image is not searchable; run OCR first.
- **Vector graphics**: Paths under a region are cut at the region's edges. Curves in a cut path are redrawn as fine straight segments (within 0.05 pt).
- **Text search needs a text mapping**: Search finds text in fonts with a standard encoding or a ToUnicode map. Text without one cannot be found by search — use coordinate redaction.
- **Refused input**: These return an error instead of a PDF:
  - encrypted PDFs;
  - form fields under a region or holding matching text;
  - text, images, or paths inside a form XObject under a region;
  - an area painted with a tiling pattern under a region;
  - a page whose `/Rotate` is not a multiple of 90, or that sets `/UserUnit`, when it has a region;
  - a region with a coordinate that is not a finite number.
- **Maximum 50 patterns per request**: Keep the total number of patterns (including those expanded from presets and templates) under 50.

## Compliance Use Cases

- **HIPAA**: Redact patient names, SSNs, dates of birth, and medical record numbers before sharing
- **GDPR**: Remove personally identifiable information from documents shared with third parties
- **FOIA**: Redact exempted information from public records requests
- **Legal Discovery**: Protect privileged information in document productions
- **Internal Audit**: Remove sensitive details before sharing reports across departments
