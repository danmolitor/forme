`POST /v1/redact`

Redacts content in a PDF by region, text pattern, preset, or saved template. Matching content is removed from the file, not only covered. See [Redaction](/concepts/redaction) for how it works.

<Warning>Use Forme 0.33.0 or later for redaction. Output from earlier versions can still contain the redacted content. If you redacted documents with an earlier version, regenerate them from the originals.</Warning>

Each successful call is one [operation](/hosted-api#operations-and-plan-limits).

---

## Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `pdf` | `string` | Yes | Base64-encoded PDF bytes |
| `redactions` | `array` | * | Rectangles: `{ page, x, y, width, height, color? }` |
| `patterns` | `array` | * | Text patterns: `{ pattern, pattern_type, page?, color? }`, with `pattern_type` `"Literal"` or `"Regex"` |
| `presets` | `string[]` | * | Built-in patterns (below) |
| `template` | `string` | * | Slug of a saved [redaction template](/hosted-api/redaction-templates). Paid plans. |

\* At least one of `redactions`, `patterns`, `presets`, or `template` is required. You can combine them. All patterns (from the template, `patterns`, and `presets`) are searched, and every match is redacted together with the `redactions` rectangles.

The fields of `redactions` and `patterns` are the same as on the self-hosted server. See the [Redact API reference](/api-reference/redact) for each field.

### Hosted limits

- **Patterns per request.** The number of entries in `patterns` is limited by plan: 10 on Free, 50 on paid plans. Over the limit returns `403`. Patterns that come from `template` and `presets` do not count toward this limit.
- **Validation.** A `pattern_type` other than `Literal` or `Regex`, a regex that does not compile, or an unknown preset name returns `400`.
- **Redaction templates** need a paid plan. On Free, a request with `template` returns `403`. An unknown slug returns `404`.

## Presets

| Preset | Matches |
|---|---|
| `ssn` | US Social Security numbers: `123-45-6789` |
| `email` | Email addresses |
| `phone` | US phone numbers, with optional `+1`, parentheses, `-` or `.` separators |
| `date-of-birth` | Dates as `MM/DD/YYYY` or `MM-DD-YYYY`, years 1900–2099 |
| `credit-card` | 16-digit card numbers, in groups of 4 with optional `-` or space |

An unknown preset name returns `400` with code `VALIDATION_ERROR`, naming the valid presets. It is not skipped: skipping it would return a PDF that still holds the values you asked to remove.

## Example

<CodeGroup>

```bash curl
curl -X POST https://api.formepdf.com/v1/redact \
  -H "Authorization: Bearer forme_sk_abc123..." \
  -H "Content-Type: application/json" \
  -d "{
    \"pdf\": \"$(base64 -w0 patient-record.pdf)\",
    \"presets\": [\"ssn\", \"email\", \"date-of-birth\"],
    \"patterns\": [{\"pattern\": \"Jane Doe\", \"pattern_type\": \"Literal\"}],
    \"redactions\": [{\"page\": 0, \"x\": 100, \"y\": 200, \"width\": 150, \"height\": 20}]
  }" \
  --output redacted.pdf
```

```javascript Node.js
const res = await fetch("https://api.formepdf.com/v1/redact", {
  method: "POST",
  headers: {
    Authorization: "Bearer forme_sk_abc123...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    pdf: fs.readFileSync("patient-record.pdf").toString("base64"),
    template: "hipaa-patient-record",
    patterns: [{ pattern: "Dr. Smith", pattern_type: "Literal" }],
  }),
});

fs.writeFileSync("redacted.pdf", Buffer.from(await res.arrayBuffer()));
```

</CodeGroup>

## Response

`200 OK`, `Content-Type: application/pdf`. The body is the redacted PDF. It is not saved to [Documents](/hosted-api/documents).

If no pattern matches and there are no `redactions`, the response is the **original PDF, unchanged**, and the call still counts as an operation.

### When Forme refuses

If Forme cannot redact a document safely, it returns an error instead of a PDF. It does not return a partly redacted file.

```json
HTTP/1.1 422 Unprocessable Entity

{
  "error": "Redaction refused: the PDF is encrypted; decrypt it first",
  "code": "REDACTION_REFUSED"
}
```

`error` says why. Refused input includes encrypted PDFs, form fields under a region or holding matching text, content inside a form XObject under a region, tiling patterns, Type3 fonts and clip-mode text under a region, and pages whose rotation is not a multiple of 90° or that use `UserUnit`. See [Known limitations](/concepts/redaction#known-limitations) for the full list. A refused call does not return a PDF.

### Errors

| Status | `code` | When |
|---|---|---|
| `400` | | `pdf` missing, or none of `redactions`, `patterns`, `presets`, `template` |
| `400` | `VALIDATION_ERROR` | Unknown preset, or a region on a page the PDF doesn't have |
| `400` | | Invalid `pattern_type` or a regex that does not compile |
| `401` | | Missing or invalid API key |
| `403` | | Over the plan's pattern limit, or `template` on the Free plan |
| `404` | | Unknown `template` slug |
| `422` | `REDACTION_REFUSED` | Forme cannot redact this document safely (above) |
| `429` | | Monthly operation limit reached, or more than 100 requests a minute |
| `503` | `REDACTION_UNAVAILABLE` | Redaction is temporarily switched off |
