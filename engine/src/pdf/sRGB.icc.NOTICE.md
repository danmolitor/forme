# sRGB.icc — embedded OutputIntent colour profile

`sRGB.icc` is the sRGB ICC profile Forme embeds as the PDF/A OutputIntent
destination profile (ISO 19005-2 §6.2). It is **generated**, not downloaded —
produced by Little CMS 2 (`cmsCreate_sRGBProfile`, via Pillow's `ImageCms`),
which builds a standard sRGB profile from the IEC 61966-2.1 colorimetry.

- **Colour model:** sRGB (IEC 61966-2.1)
- **Device class:** `mntr` (display) · **Data colour space:** `RGB `
- **Version:** ICC v4.3 · **Size:** ~588 bytes

## Regenerating

```python
from PIL import ImageCms
open("sRGB.icc", "wb").write(
    ImageCms.ImageCmsProfile(ImageCms.createProfile("sRGB")).tobytes()
)
```

Any replacement MUST keep device class `mntr`/`prtr` and colour space `RGB ` —
`engine/src/pdf/mod.rs::tests::test_embedded_srgb_is_a_valid_icc_profile`
enforces this so a bad asset (e.g. an HTML error page) can never ship silently
again. That is exactly the failure this file's predecessor, `srgb2014.icc`,
represented: a Cloudflare challenge page saved as an ICC and embedded unchecked
from ~0.9.0 through 0.15.0, making every PDF/A OutputIntent invalid.
