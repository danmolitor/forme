# purchase-order

A purchase order with delivery and coding blocks, numbered conditions of purchase, and a three-slot authorisation row. Change the supplier, lines and internal coding first; the order total is marked not-to-be-exceeded and the sample chains to remittance advice RA-20268. Line notes ride under their descriptions in the dim annotation style.

Engine features exercised: @page margin boxes with page counters, border-collapse tables, ratio split columns via explicit widths, flex signature row.
