# cover-letter

A one-page quotation cover letter on the estimating masthead, with the quoted total and decision points carried in prose rather than tables. Change the recipient, subject line and quotation reference first; the quoted total in data.json should match the quotation it covers (QUO-2026-118 in the quote template). The footer note carries the enclosures line, and the page counter reads Page 1 of 1 by design.

Engine features exercised: @page margin boxes, page counters, fixed-height page fill with a flex: 1 spacer, flex masthead.
