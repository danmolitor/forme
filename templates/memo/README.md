# memo

A one-page internal memorandum: To/From/Ref grid, bold subject, short prose, and an actions-and-owners table with due dates. Change the memo grid and the actions table first — both are mirrored in data.json. The "Internal distribution only" block replaces the address in the masthead by design.

Engine features exercised: CSS grid (fixed + fr columns), @page margin boxes, page counters, section heading, data table with th scope.
