# nda

A two-page mutual non-disclosure agreement with nine numbered clauses grouped 1–3 / 4–9 by a deliberate break, an execution block kept whole with its closing line, and Initials in both page footers. Change the parties, reference and purpose first; the clause text is standard-form and lives in the markup with its structure mirrored in data.json. Per the accent policy this document carries no coloured figure, tab or stamp — the head rule and masthead are the only accent.

Engine features exercised: @page :first, running-header margin boxes, page counters, break-before: page, break-inside: avoid on the execution block, two-column meta grid.
