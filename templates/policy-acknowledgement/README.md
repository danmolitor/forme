# policy-acknowledgement

A one-page compliance form: document head with a return-by date in the reference slot, a ten-policy table with an empty initials column, a declaration, and three signature slots whose captions never repeat. Change the employee block and policy rows first — the employee, number and cycle must stay consistent with the employment-contract and offer-letter templates (data.json links the contract reference). The initials column is deliberately empty; it is signed on paper.

Engine features exercised: @page margin boxes, page counters, four-column meta grid, data table with th scope, three-slot flex signature row.
